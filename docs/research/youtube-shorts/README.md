## Format

Each ingest folder contains:

- `README.md` — metadata, summary, takeaways, screenshot inventory, and
  mapping to claw-dj concepts
- `transcript.md` — faster-whisper transcription
- `transcript_auto.md` — YouTube auto-generated captions (when available)
- `screenshots/` — extracted frames (720px JFIF JPGs, no EXIF/GPS metadata)

Raw videos (`.mp4`) and archives (`.tar.gz`) are not committed.
