## Integration boundary

Research material proposes candidate techniques and documents external
practices. It does NOT override Ernest's musical rules. Preserve gentle
faders, backbeat matching, source exclusions, original-source performance,
human-approved passages, and the ban on unsolicited abrupt exits. A new
technique needs a scoped opt-in experiment with cues, rhythm, routing,
safeguards, cleanup, and human audition.
