# Research

External reference material relevant to claw-dj DJ technique, sample lineage,
and short-form content. This is outside-world research, not production-ready
implementation or human-approved mixing changes.

## Subfolders

| Folder | Contents |
|---|---|
| [`tiktok/`](tiktok/README.md) | TikTok DJ learning references (caption-backed notes) |
| [`tiktok-dj-transitions/`](tiktok-dj-transitions/README.md) | TikTok DJ tutorial ingests with screenshots and transcripts |
| [`youtube-shorts/`](youtube-shorts/README.md) | YouTube Shorts ingests (sample-lineage reveals, DJ technique) |

## Integration boundary

Research material proposes candidate techniques and documents external
practices. It does NOT override Ernest's musical rules. Preserve gentle
faders, backbeat matching, source exclusions, original-source performance,
human-approved passages, and the ban on unsolicited abrupt exits. A new
technique needs a scoped opt-in experiment with cues, rhythm, routing,
safeguards, cleanup, and human audition.
